## How to be listed here

Any merged change earns you a line — code, documentation, a label-fixing
triage comment that was turned into the accepted bug report, a translation,
an accessibility reproduction that made a fix testable. Open a PR against
this file with yourself added after your first merge, or ask the maintainer
to add you. Nobody is listed without their own explicit request.

## A note on sign-off

Sign-off (DCO) is optional but encouraged; see `CONTRIBUTING.md`. The
project licence (MIT OR Apache-2.0) covers all contributions regardless of
sign-off.
