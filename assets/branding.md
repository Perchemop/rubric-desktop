# Branding

Product name: **Rubric**

Tagline: *Free, cross-platform PDF markup, review & measurement.*

Description: Rubric is an original, professionally branded, 100% free/open-source desktop app for PDF markup, review workflows and precise measurements. Designed from scratch (Rust + egui/eframe) to be local-first, unencumbered and extensible.

Logo: `assets/logo.svg` (512×512, square). Icons: `assets/icons/icon_*.png` (16/32/48/64/128/256/512/1024).

Colour palette
- Ink 900: `#14172B` (deep indigo)
- Ink 700: `#1F2440` (primary background)
- Accent: `#E4572E` (rubric red-orange)
- Accent 2: `#FF7A45`
- Highlight: `#FFD654`
- Success: `#2EA86A`
- Info: `#2E86AB`
- Surface: `#FAFAFC`
- Page: `#FFFFFF`
- Line: `#D8DAE5`

Typography
- UI: Inter, system sans-serif
- Display/brand: Outfit (optional) or Inter
- Monospace: Geist Mono, JetBrains Mono

Voice
- Concise, precise, professional. No marketing fluff.

Notes
- The logo uses a "rubric mark" (a red review mark/check) over a document page, symbolising markup and measurement.
- Icons are rasterised from SVG for packaging across Windows/macOS/Linux.
