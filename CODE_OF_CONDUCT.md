# Code of Conduct

## Our standard

Everyone participating in the Rubric project — in issues, pull requests,
discussions, and review comments — is expected to behave professionally and
kindly. Concretely:

- Be patient with newcomers; every contribution type counts.
- Critique code and design, never people.
- Use plain, inclusive language. Many readers are not native English speakers.
- Assume good faith; ask clarifying questions before contesting claims.
- Respect that maintainers and contributors are volunteers with limited time.

Unacceptable behaviour includes harassment, personal attacks, trolling,
posting other people's private information, and sustained disruption of
project discussions.

## Scope

This code of conduct applies to all project spaces (repository, issue
tracker, linked chats) and to anyone representing the project publicly.

## Reporting

Report a conduct violation by opening a **private** GitHub security advisory
against the repository ("Report a vulnerability") and prefixing the title
with `CONDUCT:` — this reaches the maintainer privately. Conduct reports,
like security reports and sensitive moderation cases, are handled privately
by design; the resolution is summarised publicly when it does not expose
anyone's private information.

## Enforcement

The project maintainer reviews every report. Possible actions, from least to
most severe: a private warning, a request to edit or delete content, a
temporary ban from project spaces, or a permanent ban for repeated or severe
violations. Maintainers are held to the same standard, not a higher one.
