# Product Name — Locked

**Name**: **Rubric**

**Tagline**: *Free, cross-platform PDF markup, review & measurement.*

## Origin

- **Decision (2026-10-17)**: the name `Rubric` was invented for this project
  during discovery (guide §0, question E14: invent an original name) and has
  been locked since. It was not taken from any existing product.
- A "rubric" is a set of criteria used to score work — a natural fit for a
  document review and markup tool.

## Where the name is used

- Crate/package name: `rubric` (`Cargo.toml`)
- Window title: `<file> — Rubric` (or `Untitled — Rubric`)
- Sidecar extension: `.rubric.json`
- Branding kit: `assets/branding.md` (palette, typography, voice),
  `assets/logo.svg`, `assets/icons/`
- Config/cache directory: OS config dir (`~/.config/rubric/` on Linux)

## Rule

Any rename requires a `DECISIONS.md` entry and a traceability update; the
name above is the single source of truth for branding.
