# Bluebeam Studio – Capability-level summary

**Purpose:** original summary of publicly available capability information for Rubric v0.2 discovery. No proprietary material copied. URLs preserved for traceability.

**Sources:**
- Bluebeam markups and data product page: https://www.bluebeam.com/product/markups-and-data
- Bluebeam collaboration and mobility product page: https://www.bluebeam.com/product/collaboration-and-mobility
- Bluebeam Studio Sessions vs Projects guide: https://support.bluebeam.com/revu/subscription/studio-and-bluebeam-cloud-comparison-guide.html

**Capability themes observed:**

1. Precision markups & measurements
   - Place accurate construction markups and measurements directly on PDFs with consistent styles and standards.
   - Markup tool set includes text, clouds, callouts, highlights, stamps, shapes, freehand.
   - Ability to save favorite markups / share tool sets.

2. Markups List / audit trail
   - Track every markup and its metadata in a central list for audit-ready documentation.
   - List supports sorting, filtering, grouping, status changes, and attribution of who placed each markup.

3. Real-time and asynchronous collaboration
   - Studio Sessions enables multiple reviewers to add markups to the same PDF in real time, with built-in chat.
   - Session Record tracks activity and links back to session PDFs.
   - Asynchronous participation supported so reviewers work on their schedule.

4. Visualization & organization
   - Colors, layers, legends, filters to visualize markups and understand drawing changes.
   - Export/import markups between drawings; copy/paste between documents with same page setup.

5. Mobility / access
   - Markup and edit from web browser or mobile device.
   - Cloud-based storage and sharing.

**Rubric relevance:** Rubric is local-first and non-cloud. Capability-level inspiration from Bluebeam can inform local Markups List UI, status workflow, layer/legend grouping, and markup reuse. Real-time collaboration is out of scope for Rubric v0.2; local multi-user is not a goal.

**Notes for design:** Maintain clean-room. Do not replicate UI text, icons, or trade dress. Use only capability concepts above.
