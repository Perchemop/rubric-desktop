# Task v0.3-03 — Corpus fidelity tests for hayro rendering

**Status**: pending

## Source

Phase 3 of the v0.3-02 hayro engine slice (H8 follow-up). Goal: validate that the
hayro pure-Rust PDF rendering pipeline produces pixel-equivalent output to the
PDFium baseline.

## Goal

Implement corpus fidelity tests to validate ≥95% pixel match between hayro and
PDFium rendering engines for a representative corpus of 10 PDF files.

## Acceptance criteria (DoD)

- A corpus of 10 representative PDFs covering text, images, vector graphics, and rotated pages
- Fidelity tests that render each page with both engines and compare pixel-by-pixel
- ≥95% pixel match for all rendered pages (allowing for minor anti-aliasing differences)
- Tests runnable in CI with PDFium available
- All tests pass on main branch

## Test corpus (10 representative PDFs)

1. `text-heavy.pdf` — Multi-column text with various fonts
2. `images.pdf` — Embedded JPEG and PNG images
3. `vector.pdf` — Geometric shapes and lines (charts/diagrams)
4. `rotated.pdf` — Pages with rotation (90°, 180°)
5. `form.pdf` — PDF form fields and widgets
6. `complex.pdf` — Mixed content (text, images, vectors)
7. `simple-letter.pdf` — US Letter page, simple text
8. `simple-a4.pdf` — A4 page, simple text
9. `annotations.pdf` — PDF with existing annotations
10. `scan.pdf` — Scanned page (image-only)

## Files likely touched

- `apps/rubric/src/data/pdf.rs` — add corpus test module
- `tests/corpus_fidelity.rs` (new) — corpus comparison tests
- `tests/fixtures/pdfs/*` — test PDF files

## Implementation approach

1. Define test PDFs in the corpus directory
2. Render each PDF page with both PDFium and hayro
3. Compare rendered PNGs using image diff (allow 5% tolerance for anti-aliasing)
4. Report mismatches with diff visualization
5. Ensure tests run in CI with PDFium provisioned

## Definition of Done

- [ ] Corpus PDFs added to test fixtures
- [ ] Fidelity test infrastructure implemented
- [ ] Tests pass with ≥95% pixel match
- [ ] CI includes corpus fidelity test job
- [ ] PR opened via `ci.sh`, reviewed, merged
