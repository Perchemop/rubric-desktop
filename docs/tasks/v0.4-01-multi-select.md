# Task v0.4-01 — Multi-select markup selection

**Status**: complete (PR #86 merged)

## Source

v0.4 capability-gap analysis (docs/research/v0.4-capability-gap-analysis.md), gap #2:
> **No multi-select** — shift-click toggles in the click handler (domain
> `delete_selected`/`apply_style_to` already take id sets); then marquee, then
> Ctrl+A.

The domain already supports multi-selection: `MarkupList`, `delete_selected()`,
`paste_selected_style()`, `EditorAction::is_enabled` all operate on id sets.
Only the UI click handler and marquee drag are missing.

## Goal

Implement multi-select on the canvas so a user can select multiple markups at
once:

1. **Shift+click** toggles a markup in/out of the selection (click handler).
2. **Marquee drag** — drag an empty canvas area to draw a selection rectangle
   and select all markups whose bounds intersect it.
3. **Ctrl+A** already exists via the Edit menu ("Select All").

## Acceptance criteria (DoD)

- [ ] Shift+click on a selected markup removes it from selection; Shift+click
      on an unselected markup adds it (without clearing existing selection).
- [ ] Click (no modifier) on an empty area clears selection; click on a markup
      with no modifier replaces selection with that markup (existing behavior,
      unchanged).
- [ ] Marquee drag (drag starting on empty canvas space) draws a translucent
      selection rectangle and selects all markups whose bounds intersect it.
- [ ] Marquee drag starting on a selected markup still triggers move-drag
      (existing behavior, unchanged).
- [ ] Selection status bar text reflects count ("Selected N markup(s)").
- [ ] Unit test(s) covering Shift+click toggle and marquee selection.
- [ ] CI green (fmt, clippy -D warnings, tests).

## Implementation approach

1. **Shift+click toggle**: In the canvas click handler (`ui_state.active_tool == Tool::Select` branch), check `egui::Modifiers::SHIFT`. If held:
   - If the clicked markup is already selected, remove it from `ui_state.selected`.
   - If not selected, add it (without clearing the existing selection).
   - Update status text to "Selected N markup(s)".
   - Preserve note popover behavior for note markups.
2. **Marquee drag**: Track drag start position in screen space. While dragging
   with no markup selected under the pointer, draw a translucent rect from
   drag start to current pointer. On release, compute screen-space rect and
   select all markups on the current page whose screen-space bounds intersect
   it. If the drag started on a selected markup, treat as move-drag (existing
   behavior).
3. **Ctrl+A** already implemented via Edit menu ("Select All").
