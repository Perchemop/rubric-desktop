# Task v0.2-09 — accessibility pass (F-605)

## Requirement IDs
- F-605 (spec): accessibility — contrast, keyboard reachability, labels.
- R-S-016 (traceability): UX polish — shortcuts, dark theme, context menus,
  undo/redo, accessibility.

## Goal
Make the contrast requirement machine-checked, set audited body-text colours,
and give icon-only controls descriptive names. Keyboard reachability already
exists (per-tool shortcuts, menu accelerators, Ctrl+Z/Y/S, Page Up/Down); this
task documents it and closes the contrast/label gaps.

## Files touched
- `apps/rubric/src/domain/a11y.rs` (new): WCAG luminance/contrast maths,
  `WcagLevel`, `AuditPair`, `A11yIssue`, `audit`, with unit tests.
- `apps/rubric/src/domain/mod.rs`: register + re-export the module.
- `apps/rubric/src/ui/theme.rs`: explicit `override_text_color` per theme, a
  lighter dark-theme link accent, and the palette audit test.
- `apps/rubric/src/ui/inspector.rs`: tooltips on layer visibility/lock/reorder.
- `apps/rubric/src/ui/app.rs`: page nav arrows reordered and labelled.
- `docs/a11y.md` (new): audit table and tracked limitations.

## Acceptance criteria
- `src/domain/a11y.rs` computes WCAG relative luminance and contrast ratio;
  `cargo test` covers black/white (~21:1), identity (1:1), symmetry, the
  #767676 4.5:1 boundary, and the audit reporting only failures.
- `shipped_palettes_meet_wcag_contrast` proves the shipped chrome passes AA for
  body text and AA-large for accent selection/link pairs.
- Icon-only controls carry descriptive tooltips.
- `docs/a11y.md` records the audit, the accepted accent limitation, and the
  deferred kittest visual-evidence gap (G4).
