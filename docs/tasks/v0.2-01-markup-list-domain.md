# Task Brief – v0.2-01 Markup List Domain

**Phase:** Chat → Task

**Related discovery:** docs/discovery/v0.2-discovery.md

## Goal
Implement pure domain types for a Markups List and style reuse, plus a simple diff model for two projects, enabling headless tests and future UI.

## Acceptance criteria
- Domain types live in `src/domain/` with no UI or external deps.
- `MarkupList` provides:
  * Construction from a `Project` / `Document`
  * Filter by status, subject, author, layer
  * Sort by created_at, page, type
  * Group by chosen key
- `MarkupStyle` represents reusable visual + metadata defaults; can be applied to a new markup.
- `DiffResult` compares two `Project` snapshots and reports added/removed/changed markups with stable IDs.
- All types are `Serialize`/`Deserialize` via serde.
- Unit tests cover happy path, filter edge cases, empty project, sort stability, diff identity, diff change detection.
- Tests run headless, no display required.
- No proprietary material.
