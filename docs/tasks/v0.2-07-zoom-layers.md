# Task v0.2-07 — zoom presets (F-401) & layer rename/reorder (F-004)

## Requirement IDs
- F-401 (spec `docs/spec/README.md`): zoom — wheel, fit, presets.
- F-004 (legacy): layers/toolsets — visibility/lock shipped; rename/reorder this task.
- R-S-011 (traceability): canvas navigation.

## Goal
Close the last two open sub-items on the roadmap: numeric zoom presets in the
View menu, and layer rename/reorder in the Inspector. Reorder must actually
change stacking, not just reorder a list that the renderer ignores.

## Files likely touched
- `apps/rubric/src/domain/view.rs` (new): zoom constants and preset list.
- `apps/rubric/src/domain/mod.rs`: export `view`.
- `apps/rubric/src/domain/document.rs`: `markups_in_paint_order`,
  `rename_layer`, `move_layer_up`/`move_layer_down`, layer-scoped z-order.
- `apps/rubric/src/ui/canvas.rs`: paint/measure/hit-test through paint order.
- `apps/rubric/src/ui/inspector.rs`: editable layer name, ▲/▼ buttons.
- `apps/rubric/src/ui/app.rs`: View-menu presets, domain zoom constants.

## Acceptance criteria
- View menu offers 50 %, 100 % and 200 % zoom presets; `ZoomIn`/`ZoomOut` use
  `view::MIN_ZOOM`/`MAX_ZOOM` (no magic numbers).
- Inspector layer name is editable; blank names are refused.
- ▲/▼ move a layer within the order; the default layer stays at index 0 and
  cannot be moved; `Layer::z` mirrors the layer's index.
- Paint order is layer-major: reordering layers changes stacking. Canvas paint,
  measurement labels and hit-testing all use the same order.
- Bring Forward / Send Backward / To Front / To Back stay within the selected
  markup's page and layer.
- Tests cover rename, reorder + pin + `z`, paint order, and layer-scoped z-order;
  existing page-scoped z-order tests still pass.
