# Task v0.3-05 — lopdf write support for PDF export

**Status**: complete (PR #79, #81, #82, #83, #84 merged)

## Summary
- `lopdf 0.42.0` added as a dependency (pinned exact; 0.6.0 has RUSTSEC-2026-0187)
- `export_pdf_to()` implemented in `data/pdf.rs`: opens source PDF, appends
  overlay content stream to each page via lopdf `add_to_page_content()`, saves
  result. Renders BBox/Segment/Path/Ink markups with stroke color, width, fill
  mode. Domain coords (y-down) flipped to PDF coords (y-up).
- File ▸ Export PDF… menu item with native `rfd` save dialog
- Full markup overlay rendering: BBox/Segment/Path/Ink/Text/Callout/Angle/Count
- Scale calibration: page scale is already reflected in pre-computed domain
  measurements (geometry in page points, text labels pre-formatted with correct
  page-unit values), so no additional scaling is needed for export
- Export respects page boundaries via MediaBox dimensions

## Goal

Add `lopdf` dependency and implement PDF export functionality to allow users to save their markups back to PDF format (non-destructive, sidecar-based export).

## Acceptance criteria (DoD)

- [x] `lopdf` added as a dependency with exact version pin
- [x] PDF export function that writes markups over the original PDF background
- [x] Export respects page boundaries (MediaBox) and scale calibration
  (measurements pre-computed in domain with correct page-unit values)
- [x] User can choose export location via native file dialog
- [x] Honest status messages on export success/failure

## Files touched

- `apps/rubric/Cargo.toml` — lopdf dependency
- `apps/rubric/src/data/pdf.rs` — export_pdf_to() + markup rendering
- `apps/rubric/src/ui/app.rs` — File > Export PDF… menu item

## Implementation approach

1. Add `lopdf` with exact version pin (0.42.0, avoids RUSTSEC-2026-0187 in 0.6.0)
2. Implement `export_pdf_to()` function — loads PDF with lopdf, appends overlay
   content stream per page via `doc.add_to_page_content()`, saves
3. Render markups to PDF drawing operations (rect, line, polyline, strokes,
   text) with y-flip (domain y-down → PDF y-up)
4. Add UI menu item (File > Export PDF…)
5. Unit tests for export_pdf_to
